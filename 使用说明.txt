图影盒 v1.1 · Windows 64 位便携版

在软件文件夹第一层双击「图影盒.exe」。如果使用便携 ZIP，请先完整解压。运行组件已随包提供。
窗口、字体和控件会按 Windows 显示缩放调整，可调整窗口大小。
默认下载目录为 %USERPROFILE%\Downloads\图影盒。运行时会定位到当前账号的用户目录。可在主窗口更改。

下载图片
• X / Twitter：输入 @账号、主页或帖子链接。可设置起始日期 YYYY-MM-DD 和最多图片数。
  默认处理 50 张。文件名包括日期、帖子编号和图序，重复运行会跳过已存在的文件。
• Instagram：粘贴帖子链接，下载图文中的图片。登录时使用该站点的 Cookies。
• 抖音图文：粘贴图文链接或分享文案。优先保存网页提供的原图，并按作品 ID 建文件夹。
  直接解析不到图组时，程序会尝试使用随包附带的 Chromium 浏览器渲染网页。

下载视频
• 支持 YouTube、X / Twitter、哔哩哔哩和抖音，可逐行粘贴多个链接。
• YouTube 自动配置 Deno。yt-dlp 在处理 JavaScript 挑战时调用它。
• 默认下载当前视频。勾选「允许下载完整播放列表」后也可下载完整列表。
• 抖音视频的 yt-dlp 下载失败时，会尝试使用抖音分享页或网页播放器提供的视频流。

编辑图片
• 添加或拖入图片，使用「上移」「下移」排序。可选竖向和横向拼接，输出为 PNG。
• 右侧预览会随方向和顺序实时更新，并显示成品尺寸。
• 竖向拼接按第一张图的宽度对齐，横向按第一张图的高度对齐。透明区域用白色合成。

格式转换
• 先选任务与输出格式，再添加或拖入文件。输出目录留空时保存到各源文件的目录。
• 视频可转 MP4、MKV、MOV、WebM。自动模式先尝试无损封装；也可指定仅做无损封装或重新编码。
• 变速默认保持音高。倍率可设 0.25–4，固定时长可填秒数、分:秒或时:分:秒。
• 提取或转换音频时，可在列表选中输入文件并查看可用音轨。批量作业对每个输入使用相同音轨序号。
• NCM 默认还原原始 MP3 或 FLAC。其他输出格式可从菜单选择。
• 图片可转 PNG、JPG、WebP、AVIF、GIF、ICO、PDF，并可组合等比缩放和旋转。输出静态格式时使用第一帧。
• 队列显示每个文件的状态。遇到同名文件自动编号。点击失败行可查看原因，完整输出在任务日志中。
• 点击「停止转换」可停止当前文件和等候中的文件。点击窗口关闭按钮可以选择停止转换并退出。已完成的文件会保留。

Cookies 设置
• 在主窗口点击「Cookies 设置」，可直接填写路径，或点「浏览」打开 Windows 文件选择器。
• 各站点使用各自的 Netscape 格式 .txt 文件。JSON 和 Header String 不支持。公开内容可先留空尝试。
• settings.json 只保存用户填写的路径和下载目录。Cookies 文件需要由用户自行保管。
• 登录、访问或下载失败时，可在底部任务日志查看提示。网站响应和账号状态会影响下载。
• 界面或启动发生异常时，错误对话框会给出 error.log 的保存位置。
